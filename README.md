# CuePilot releases

Signed and notarized builds of [CuePilot](https://github.com/SurajAdsul/cuepilot-releases/releases/latest), a macOS menu bar app that rewrites selected text with AI.

Download `CuePilot-arm64.dmg` from the [latest release](https://github.com/SurajAdsul/cuepilot-releases/releases/latest). It runs on Apple silicon Macs.

CuePilot checks this repo's releases for updates. You can turn that off in CuePilot's Home window under General, Updates.

This repo holds release files only. It has no source code.
